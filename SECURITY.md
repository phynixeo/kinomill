# Security policy

Please report security problems **privately**: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and the Kinomill version (Settings → Components shows it). You will get a reply as soon as possible. Fixes ship in a new release.

Only the latest release is supported.

Kinomill stores login cookies only on the user's PC (`%APPDATA%\Kinomill`). Never include real cookies or account details in a report.
